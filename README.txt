1. Create a new GitHub repo, upload everything in this folder (keep the .github folder).
2. Actions tab > "Build APK" > wait ~3-4 min.
3. Open the finished run > Artifacts > ThugTV-apk > extract app-debug.apk.
4. Copy to the TV (USB / Send Files to TV / adb install app-debug.apk).

Remote controls
- Arrows: move cursor (hold to speed up; push past the top/bottom edge to scroll)
- OK: click
- Menu / Red / *: turn cursor off/on
- Back: back / exit fullscreen
- When a video stream is detected, a red "Play in player" button appears top-right:
  move the cursor onto it and press OK (or press the Play / Yellow key).
- In the native player: Left/Right = seek 10s, OK = pause/play, Up/Down = show controls.
